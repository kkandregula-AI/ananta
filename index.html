01THE PROBLEM

The Quadratic Wall

Self-attention is the transformer's superpower and its ceiling. Every token looks at every other token — so doubling the context quadruples the work.

Inside one attention layer, each token produces a query and every token produces a key. To decide what to pay attention to, the model scores every query against every key. With n tokens that's n × n scores — an entire matrix that grows with the square of the sequence.

At 2,000 tokens that's 4 million comparisons. At 1 million tokens it's a trillion. This is why long context has historically been so expensive: the cost isn't in the model's size, it's in the shape of attention itself.

02THE STAKES

Reading the Cost Curve

The same curves as the hero, but now yours to interrogate. On a log–log plot the wall is unmistakable: quadratic pulls away from linear, and never comes back.

In May 2026, a Miami startup called Subquadratic shipped SubQ — the first commercial LLM to claim a 12-million-token context window, a length that would be economically absurd for full attention. Its architecture (SSA, Subquadratic Selective Attention) is a learned sparse scheme — each token attends only to the handful it deems relevant — so it belongs to the Sparse / Local escape below rather than to linear attention or SSMs. The reason a jump like that becomes possible is entirely in the slope of these lines: beyond a certain length, the architecture matters more than the parameter count.

A note on honesty: SubQ's headline efficiency figures (52× faster, ~1,000× cheaper) are vendor-reported, single-shot, and not yet independently reproduced. The 12M window and the subquadratic shape are the durable, verifiable part — the exact multipliers still await outside confirmation.

Reading the three lines

Transformer

Full attention · O(n²)

The classic design. Every token attends to every other token — exact, all-pairs recall, but the work grows with the square of the length.

Sparse

Selective / windowed · O(n·√n)→O(n)

Still real attention, but rationed — each token attends only to a chosen window or pattern. Cheaper, at the risk of missing links off the pattern. (SubQ's SSA lives here.)

Linear / SSM

Running summary · O(n)

Drops the n×n step entirely — folding the past into a fixed-size running summary (linear attention) or a recurrent state (state space models). Scales flat with length.

04THE JUDGEMENT

The Tradeoff Ledger

Subquadratic isn't free — you give up exact, global, all-pairs attention. Whether that matters depends entirely on the job. Pick a workload.

A pragmatic rule of 2026: most shipping systems are hybrids — a few full-attention layers for precise recall, stacked with many linear or SSM layers for cheap reach.

Where this actually lands in 2026

The honest picture: the transformer still runs the world. Most frontier models you use daily are full-attention, capped around 128K–1M tokens. Subquadratic is the fast-moving frontier, not yet the default — but it's where the next unlock in long context is coming from. Concretely, it matters most in:

Long-context over RAG

A large enough native window (SubQ's pitch) can let a model read a whole corpus directly instead of retrieving snippets — simplifying or replacing RAG plumbing where it fits.

Agents with long memory

Agents that accumulate huge histories are exactly where a growing KV cache hurts. Recurrent SSM-style memory keeps cost flat as the transcript grows.

On-device & edge

Constant memory per step is what makes meaningful context feasible on phones and laptops, where a quadratic cache simply won't fit.

Genomics & long signals

DNA, audio, and sensor streams are enormously long with local structure — the setting where SSMs have posted their clearest wins.

Cheaper serving at length

Below ~8K tokens the savings are marginal; past a few hundred K they're the whole ballgame, which is where cost-sensitive long-context products lean subquadratic.

The realistic form: hybrids

In practice you rarely go pure. Production designs blend a few full-attention layers for sharp recall with many cheap subquadratic layers for reach.

Bottom line for a builder in 2026: reach for subquadratic when context length is your cost or latency ceiling; stay with full attention when exact recall over short context is the job. Watch the space — the ground is still moving.
